Featured Work

Selected data and ML infrastructure projects spanning distributed systems, data pipelines, and analytics platforms.

Multimodal Robotics Data Engine
(GitHub Repo)

Designed and built a deterministic data engine that transforms raw robot video and sensor logs into aligned, versioned, training-ready datasets. Serves as a reusable data infrastructure layer for robotics ML workflows, with scalable ingestion, cross-modal timestamp alignment, invariant-based validation, and dataset health metrics. Enables reproducible dataset construction and reliable downstream model training.

Synthetic EHR ETL Pipeline (Synthea + Databricks)
(GitHub Repo)

Built a production-style healthcare data pipeline in Databricks using PySpark, transforming synthetic EHR data into validated, analytics-ready datasets with a Bronze/Silver/Gold architecture. Implemented schema standardization, distributed transformations, and data quality checks (referential integrity, temporal validation) with structured validation outputs for downstream analytics.

Synthetic EHR Analytics Pipeline (Snowflake)
(GitHub Repo)

Built a SQL-based analytics pipeline in Snowflake, transforming synthetic EHR data into validated, analytics-ready tables. Designed relational data models and transformation layers, and implemented data quality checks (referential integrity, null/duplicate detection, temporal validation) to ensure consistency for downstream analytics.

Kubernetes-Deployed ML Inference Service (FastAPI + Ray)

Designed and built a production-style ML inference service combining FastAPI and Ray, deployed on Kubernetes. Supports concurrent request handling with batching, explicit backpressure, resource limits, readiness and liveness probes, and horizontal autoscaling. Instrumented with Prometheus-compatible metrics to monitor latency, throughput, and system health under bursty load.

Sentinel — Automated Red-Teaming & Safety Evaluation Platform for Vision-Language Models
(Technical report)

Built a distributed evaluation platform that stress-tests vision and vision-language models under structured perturbations, with reproducible audits via Ray-parallel execution and structured reporting.

Robotics Perception & Data Infrastructure — xLab (Safe Autonomous Systems Lab) / University of Pennsylvania

Built pipelines and tooling for multi-camera perception systems for autonomous forklifts, including data ingestion, labeling workflows, dataset QA, and robustness evaluation (occlusion, lighting variation, sensor noise) in collaboration with a global logistics partner.

VidFlow — Scalable Robotics Video Compression & Evaluation Pipeline
(Technical report)

Developed a Ray-parallel benchmarking pipeline that quantifies compression–quality tradeoffs for robotics perception video. Measures perceptual and semantic degradation (PSNR/SSIM/LPIPS/CLIP) to inform storage and ingestion defaults at scale.

Serial Load: Visual Safety Benchmark for Vision-Language Models
(Paper)

Developed a controlled benchmark probing how increasing visual reasoning load affects safety judgments, highlighting uncertainty and rare false-safe failures missed by standard accuracy metrics.
